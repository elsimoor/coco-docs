# Recherche globale

Adresse : `/search`. Titre : **Recherche Unifiée**.

<Sketch scene="recherche" />

La page cherche en une fois dans les contacts, organisations, dossiers, devis, factures et messages de l’espace actif. Le même champ existe dans l’en-tête (`Ctrl+K`).

Une **vue enregistrée** réapparaît dans le groupe **Vues** du menu. Son lien rouvre la recherche avec l’étape, le statut ou le nom de la vue.

La recherche ne calcule pas d’indicateur. Elle retrouve les pièces dont les indicateurs sont faits. Les éléments en corbeille n’y figurent plus tant qu’ils ne sont pas restaurés.
