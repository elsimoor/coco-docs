# Discussion d’équipe

Adresse : `/chat`. Titre : **Discussion d'équipe & Chat Interne**.

<Sketch scene="discussion" />

Cette page ne contient pas le chat. Elle explique que les canaux, les fils, les réactions, les pièces jointes, la boîte unifiée et la téléphonie sont sur la plateforme CocoInbox Connect. Le bouton **Ouvrir le Chat sur CocoInbox Connect** ouvre cette plateforme dans un nouvel onglet. Ce n’est pas la connexion unique du sélecteur de produit : le sélecteur ouvre `/emails`, ce bouton ouvre `/chat`.

## Discussion attachée à une fiche

Le chat interne que vous utilisez sans quitter le CRM est le volet **Discussion interne**. Il est présent sur un projet, un dossier, un devis ou une facture, et sur la fiche client. Il est limité à cet élément. Le bandeau dit **Confidentiel interne**. Vous pouvez filtrer, mentionner un collaborateur ou un agent (@Emma, @Alex, @Omar, @Nora), joindre un document, épingler un message et réagir.

## Appels

Il n’y a pas d’écran d’appels dans le menu Connect. L’appel part de la fiche client : **Appeler** ouvre la téléphonie d’entreprise. Le numéro sortant dépend du pays (France, Maroc, Canada). Les issues proposées sont : discussion utile, messagerie, occupé, pas de réponse. Un enregistrement demande le consentement légal, puis le compte-rendu est écrit dans l’historique du client.

Le taux de rappel des appels manqués, lorsqu’il est affiché dans les rapports, compte un appel terminé sans durée ou sans participant comme manqué, et un rappel comme un appel abouti du même correspondant dans les 60 minutes. Voir [Connect et activité](../calculs/connect).
