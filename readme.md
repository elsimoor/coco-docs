# Documentation Coco

Site Docusaurus des produits **Coco Sells** et **Coco Connect**. Il décrit chaque écran et la façon dont les indicateurs sont calculés. Le thème est en mode clair.

```bash
cd COCO_Docs
npm install
npm start
```

Le site s’ouvre sur `http://localhost:3000`. Pour produire la version statique : `npm run build`, puis `npm run serve`.
